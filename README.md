# Slide Studio 4 — Macアプリと保存一覧

## Mac版を使う

Apple Silicon / macOS 15以降向けの `Slide Studio.app` を同梱しています。ZIPを展開し、アプリをApplicationsへ移して開きます。Node.jsは同梱しているため、ターミナル起動・Nodeのインストール・Bridge tokenの入力は不要です。Developer ID署名・Appleの公証は未実施です。初回にmacOSが起動を止める場合は、システム設定の「プライバシーとセキュリティ」でこのアプリの開く操作を確認してください。

既存のブラウザ版の資料は、まず旧版で「書き出し → プロジェクト .slide」で保存し、Mac版の「.slideを取り込む」か「ファイル → .slideを開く」で取り込んでください。ブラウザ内部の自動保存領域はMac版から直接読みません。既存のブラウザ版のプロジェクトデータはそのまま保持されます。

### 保存と一覧

- 「保存」または⌘ Sで、発表全体を保存一覧へ保存。同じ発表の再保存は一覧内の同じ項目を更新。
- 「保存一覧 → この1枚を保存」で、選択中のスライドと参照している素材だけを別の項目として保存。
- プレビュー、名前・見出し検索、発表／1枚保存の絞り込み、更新日時を表示。
- 「開く」で再編集。「今の発表に追加」で他の発表へ再利用。素材・要素のIDを衝突しないよう再生成。
- 「別名で保存」または⌘ Shift Sで、元の保存項目を保持してコピーを作成。
- 編集中の状態は「下書き保存済み」として自動保存。保存一覧の明示保存とは別で、次の起動時に作業状態を復元。
- 別の発表を開く／新規作成する前に、現在の発表を保存一覧へ保存して保護。
- 保存先は `~/Library/Application Support/Slide Studio/saved-presentations/`。「ファイル → 保存フォルダを表示」で開けます。アプリ本体を置き換えても保存内容は残ります。
- .slide、HTML、画像の書き出しにはmacOSの保存ダイアログを使用。
- 写真・動画等をファイルとして読み込んだ素材は保存に含みます。http(s)参照の素材・YouTube/Vimeoはネット接続と元の公開状態に依存します。

### Codex

Macに公式ChatGPT/Codexアプリ、またはCodex CLIが必要です（Codex自体や認証情報は同梱しません）。AI設定からログイン確認とモデル取得を行ってください。接続トークンはアプリが自動設定します。選んだモデルと接続方式を下書きとともに保存しますが、APIキーや会話・添付は永続保存しません。公式ChatGPTアプリ内のCodexを、古いCodex.appより先に探します。

### 共同作業の範囲

今回実装したのは `.slide` の受け渡しと、同じサーバーの保存項目に対する版番号の競合検出です。別の画面が先に保存していた場合は上書きを拒否し、別名で保存できます。インターネット経由の共同編集、メンバー招待、同時カーソル、端末間同期は未実装です。Mac版サービスは127.0.0.1のみで待ち受け、LANやインターネットへ公開しません。

### Web版との関係

編集画面・保存一覧は共通のHTML/CSS/JavaScriptです。ブラウザ版でも保存一覧を利用できます。接続トークンが設定済みのローカルサーバーでは `saved-presentations/` にファイル保存し、サーバーに未接続ならブラウザ内に保存します。この2つの保存領域は別です。後で公開Web版の保存・認証・同期APIを差し替えられるようにしています。Webでのオンライン公開は今回行っていません。

### ビルドと検証

`npm run build:mac` で、Node.jsとSwift環境から `.app` を再ビルドできます。Node公式配布版の、システムライブラリ以外に依存しないバイナリを使ってください。出力は `release/`。既存のアプリを上書きしないため、再ビルドは `SLIDE_STUDIO_BUILD_DIR=/別の出力先 npm run build:mac` を指定します。Apple Silicon版とIntel版はそれぞれ対応するMac・Nodeでビルドしてください。

自動検証に加え、Swiftのコンパイル、アプリへのNode・Web画面の同梱、アドホック署名の整合性、同梱リソースの自己診断を実施。ネイティブ画面の実操作、実際のCodex生成、YouTube/Vimeoや複数ディスプレイでの実機確認はこの制作環境では未実施です。ローカルHTTP待ち受けを伴う起動は検証環境の制約があるため、初回起動時に確認してください。

# Slide Studio 3

VS Codeを参考にした、自由配置・映像・音声・会話によるAI編集に対応するプレゼンテーション制作環境です。エディタ本体の外部npmパッケージは不要。Codex連携には公式CodexアプリまたはCLIが必要です。ローカルサーバーはNode.js 22以上で動作します。

## まず使う

1. ZIPを展開します。
2. **編集だけなら** `dist/slide-studio.html` をChromeで開きます。
3. **AI・発表者同期・動画埋め込み・TD連携を使うなら** Macで `start-slide-studio.command` を開くか、フォルダ内で `node server.mjs` を実行します。
4. 表示された `http://127.0.0.1:4317` をChromeで開きます。

右上の「AIと作成」→「AI設定」で、起動時に表示されるBridge tokenを入力します。接続方式は標準で「Codex · ChatGPTでログイン」です。

1. 「接続確認・モデル取得」を押す。ログイン済みなら、そのまま利用できます。
2. 未ログインなら「ChatGPTでログイン」→表示されるリンクを開いて公式の認証を完了。
3. この画面でログイン済みになったらモデルを選び、「設定を保存」。「自動選択」は一覧からモデルを明示指定します。モデル非対応のエラーのみ別候補へ切り替えます（最大3候補）。一覧に載っていてもアカウントの利用権限は保証されません。利用上限・認証エラー・生成中断では自動再試行しません。
4. チャットで依頼し、提案されたスライドの変更を確認して適用します。

CodexモードはAPIキー不要です。ChatGPTプランのCodex利用枠・利用上限に従います。APIキー認証のCodexアカウントでは生成を開始しません。ChatGPTでログインしてください。

MacではPATH上の`codex`、続いて`/Applications/Codex.app/Contents/Resources/codex`、ChatGPTアプリ内のCodexの順で自動検出します。見つからなければ公式CLIを `npm install -g @openai/codex` でインストールしてください。別の場所なら `SLIDE_STUDIO_CODEX_BIN` に実行ファイルの絶対パスを指定できます。

従来のAPI方式も「OpenAI API」で選べます。APIキー・APIモデルIDを入力してください。この方式は別途従量課金で、環境変数 `OPENAI_API_KEY` も利用できます。

## 編集

- 上のツールバー：テキスト、素材、YouTube/Vimeo、図形、表、棒グラフを追加。
- 既存の固定レイアウト：「自由配置」で編集可能な要素へ変換。以前の.slideも読み込めます。
- 要素をドラッグで移動。四隅・辺のハンドルでサイズ変更。Shiftで比率を維持、Altでスナップを一時解除。
- テキストはクリックで、その位置にカーソルを出して直接入力。Enterで改行、Escまたは⌘/Ctrl Enterで編集終了。文字の上では範囲選択でき、枠上部の↔ハンドルで移動、四隅・辺でサイズ変更。入力は随時自動保存し、編集を終えてからUndoするとその編集をまとめて戻せます。文字をドラッグして範囲選択すると上部の書式バーで選択部分だけサイズ・太字を変更できます。⌘/Ctrl Bでも太字を切り替えます。サイズを入力して「サイズを適用」を押すかEnterで確定。部分書式はtextRunsとして保存し、.slide/JSON・HTML・SVG/PNGで維持します。右側の文字サイズ・太字はボックス全体に適用し、その項目の部分指定を解除します。斜体・下線・色・行間・整列はボックス全体の設定です。
- Shift＋クリックで複数選択。右側で整列、均等配置、グループ化、重なり順を操作。
- 左のレイヤーパネルで選択、ロック、非表示。左のスライド一覧はドラッグで並べ替え。
- 図形は四角・円・線・矢印・三角。表は改行で行、Tabで列を編集。グラフは数値・ラベルを入力。
- スライド背景、要素の回転・透明度、リンク、フェード等の表示効果を設定。
- 「クリック表示」は0で即時、1で最初のクリック、2で2回目のクリックに表示。
- コピー・貼り付け・複製・削除・Undo/Redo。右クリックでキャンバス操作メニュー。

| キー | 操作 |
|---|---|
| ⌘/Ctrl S | プロジェクト保存 |
| ⌘/Ctrl Z、Shift Z | Undo、Redo |
| ⌘/Ctrl C、X、V、D | 要素のコピー、切り取り、貼り付け、複製 |
| ⌘/Ctrl A | 全要素選択 |
| 矢印、Shift＋矢印 | 選択要素を1px、10px移動 |
| Delete / Backspace | 選択要素を削除 |
| ⌘/Ctrl K | コマンドメニュー |
| F5 | 発表開始 |
| 発表中の左右キー・Space | ページ移動・段階表示 |
| B、Esc | 暗転、発表終了 |

## 素材・発表

画像・動画・音声を左の素材パネルへ追加し、「このスライドへ」で要素として配置します。画像・動画は全体表示／枠を埋めるトリミング、回転、サイズ、角丸を設定できます。動画・音声は開始・終了位置、音量、ミュート、自動再生、ループを設定します。

YouTube・Vimeoは動画ページのURLを貼り付けます。YouTubeの短縮URL・Shorts、Vimeoの限定公開ハッシュにも対応。動画側の埋め込み制限・プライバシー設定やネット接続の影響を受けます。YouTubeはfile://で開くと参照元制限で再生できない場合があるため、ローカルサーバー版を利用してください。YouTubeは開始・終了、Vimeoは開始・ミュート・ループを扱います。Vimeoの終了位置・埋め込み動画の細かな音量制御は未対応です。

「素材再生」でプレビュー、「発表する」で全画面。「発表者画面」は同一ブラウザ・同一オリジンの別ウィンドウでノート、次のスライド、タイマーを表示します。Rでタイマーをリセット。別モニターへの配置はご自身で行います。自動再生がブロックされたらプレイヤーの再生ボタンを押してください。

## 保存・書き出し

| 形式 | 内容 |
|---|---|
| .slide | 要素、設定、ノート、読み込んだ素材本体を含むJSONプロジェクト |
| HTML | 自由配置と映像・音声・埋め込み・段階表示を含む共有用ファイル。ノート・会話・APIキーは除外 |
| PDF | ブラウザの印刷画面から保存。動画・音声は静止した枠 |
| PNG | 現在のスライドを1920×1080で画像保存 |
| SVG | 現在のスライドの文字・図形等をベクター形式で保存 |
| Markdown | テキスト・ノート・埋め込みURL。自由配置や素材本体の完全な往復には.slideを使用 |

ブラウザのIndexedDBに自動保存しますが、端末間の自動同期はありません。ファイルへの保存も行ってください。素材1件200MB、ローカルAPIのプロジェクト300MBが上限です。URL参照の素材は別途アクセスできる必要があります。PNG/SVGはURL画像のCORS制限やフォント差の影響を受けます。動画はプレビュー時のフレーム、音声・埋め込み動画はプレースホルダーになります。

## AIチャット

入力した会話と、スライドの文章・ノート・配置・素材の名前を、選んだ方式でOpenAIへ送ります。添付以外の素材本体は送信しません。Codexは公式App Serverを子プロセスとして起動し、stdioのJSON-RPCで接続します。ChatGPTやVS Codeの画面そのものを埋め込む方式ではありません。

AIは会話の返答と編集操作を返します。「変更を確認」→「適用」で反映し、一度のUndoで戻せます。生成中に手動編集した場合は、その変更を上書きせず現在の内容へ再適用して確認します。生成時の構造化出力で各操作の`op`を必須にし、操作名を列挙して指定します。スライド・要素・変更内容をデコードして従来の編集操作へ変換します。要素の更新で既存と同じid・typeが含まれていても受け付けます。異なるID・種類への変更は拒否し、種類の変更は削除と追加で行います。不正な返答は検証で拒否します。Codexは推論強度mediumで実行し、ローカルCodexの高い推論設定を引き継ぎません。生成の待機上限は標準10分です。10秒ごとに経過時間を更新し、手動キャンセルもできます。`SLIDE_STUDIO_CODEX_TIMEOUT_MS`で待機上限をミリ秒単位で変更できます（最大1時間）。API方式では入力・出力トークン数も表示します。

Codexは各依頼を一時的なスレッドで実行します。直近24件の会話と最新スライドを送るため、画面を開いている間は会話を続けられます。会話は再起動後に復元しません。既存のChatGPTチャット・メモリー・別のCodex会話は自動で引き継ぎません。Codex認証情報の保存・更新は公式Codexが管理し、このアプリはOAuthトークンを読み取りません。ログインは他のローカルCodexクライアントと共有される場合があります。

Codexスレッドはread-only・承認要求なしで起動し、編集はJSONの提案として返します。ファイルを直接書き換える操作や対話的なツール承認は提供しません。画面で承認するまでスライドには反映しません。

APIキー・Bridge tokenはメモリにのみ保持し、保存ファイルには含めません。サーバーは `127.0.0.1` のみで待ち受け、API操作にトークンを要求します。API方式の返答保存は `store:false` です。会話を保存・エクスポートする機能はありません。

外部エージェントを使う場合、「JSON編集」から指示＋データをコピーし、返ってきた操作配列を貼り付けます。対応操作は `slide.add/update/delete/move`、`element.add/update/delete/order`、`theme`、`deck.update`。従来の `add/update/delete/move` も利用できます。

```json
[{"op":"element.add","slideId":"既存のスライドID","element":{"id":"unique-text-id","type":"text","text":"新しい見出し","x":160,"y":180,"w":1100,"h":150,"fontSize":72,"bold":true,"color":"#ffffff"}}]
```

## チャットへの添付

チャット入力欄の「📎 添付」、チャット領域へのドラッグ＆ドロップ、画像のペーストに対応します。1件10MB・1会話8件までです。

- テキスト・Markdown・CSV・JSON・コード等：UTF-8の文章を参考資料として送信。
- PDF：MacのPDFKitで文章を抽出。画像だけのスキャンPDF・OCRは未対応。Mac以外は`pdftotext`が必要。
- Word（DOCX/DOC/RTF）：Macのtextutilで文章を抽出。書式・埋め込み画像は渡しません。
- PNG/JPEG/WebP：Codexへ画像入力として渡します。選択モデルの画像対応が必要です。

添付一覧の「×」で送信前のファイルを外せます。「素材へ」は添付画像をスライド用素材へ追加するボタンです。追加後に「この画像を右半分に置いて」とAIへ依頼できます。添付のみでも送信できます。

文章は1件15万文字・合計25万文字までです。添付内容は参考資料であり、資料中の指示をアプリの操作指示として扱わないようAIへ伝えます。添付した文章・画像はOpenAIへ送信されます。

添付は一時ファイルで、.slideや共有HTMLには含めません（「素材へ」で追加した画像は通常のスライド素材として保存対象です）。サーバー再起動後は添付し直してください。チャットクリア・添付削除・正常終了で一時ファイルを削除します。強制終了時はOSの一時領域に残る場合があります。動画・音声・PPTXはチャット添付には未対応で、動画・音声は既存の素材パネルを利用してください。

## ローカルファイル・TouchDesigner

接続パネルに起動時のトークンを入力してBridge接続。下の「ファイルに保存」で `project/deck.json` へ保存し、エージェントはこのファイルを編集します。外部更新を確認して読み込めます。ブラウザ編集の自動保存とファイルへの保存は別々です。

WebSocket DATを `ws://127.0.0.1:4317/?token=YOUR_TOKEN` に接続。スライドのCueを設定すると表示時にJSONを送ります。Callbacks DATで `json.loads` して受け取れます。`{"type":"navigate","direction":"next"}` をTDから送るとページを進めます。フレーム単位のAV同期は保証しません。

`SLIDE_STUDIO_PORT` でポート、`SLIDE_STUDIO_TOKEN` で固定トークンを設定できます。必要な場合のみ `SLIDE_STUDIO_ALLOWED_ORIGIN` で追加のWebオリジンを許可します。ローカルAPIは `GET/PUT /api/project`、`POST /api/ai`、`GET /api/codex/status`、`GET /api/codex/models`、`POST /api/codex/login`、`POST /api/codex/chat` でBearer認証を使います。

## 対応範囲と検証

これは主要な編集・素材・発表・AI作成機能を備えた自作ツールです。PowerPoint / Keynote / Google Slidesの全機能互換ではありません。PPTX/Keynoteの読み書き、クラウド共同編集、複雑な画像マスク、モーフ・高度なタイムライン、録画、スマホ遠隔同期、ネイティブ数式・3Dモデルは未対応です。

```sh
npm run check
npm test
npm run build
```

保存一覧の検証を含む自動テストが通過。APIと通信部分は模擬応答・ソケットで検証しています。制作環境の制限により、ブラウザでの実操作、ローカル待ち受け、実際のOpenAI API/Codexによる生成・画像理解、YouTube/Vimeoの実再生、TouchDesigner実機、オンライン公開は未確認または未完了です。インストール済みCodexのバージョンと生成したプロトコルスキーマも確認していますが、この制作セッションではCodex状態保存先への書き込みが拒否されるため、実ログインと生成は未確認です。通常のターミナルから起動して接続を確認してください。
